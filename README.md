# TaskManager — برنامه ساده مدیریت وظایف

تمرین شماره ۱ (انفرادی) — یک برنامه کنسولی ساده به زبان Python برای مدیریت وظایف روزانه.

## قابلیت‌ها
1. **اضافه‌کردن وظیفه** — دریافت عنوان و ثبت وظیفه جدید با شناسه یکتا
2. **نمایش فهرست وظایف** — نمایش شناسه، وضعیت (`[ ]` / `[x]`) و عنوان
3. **حذف وظیفه** — حذف بر اساس شناسه
4. **مشخص‌کردن وضعیت انجام‌شده** — علامت‌گذاری وظیفه به‌عنوان انجام‌شده
5. **ذخیره‌سازی در فایل** — ذخیره خودکار در `data/tasks.json` و بارگذاری هنگام اجرا

## ساختار پروژه
```
TaskManager/
├── main.py        # نقطه ورود و منوی برنامه
├── tasks.py       # منطق وظایف و ذخیره/بارگذاری فایل
├── README.md
└── data/
    └── tasks.json # محل ذخیره وظایف
```

## نحوه اجرا
نیازمند Python 3.8 یا بالاتر (بدون وابستگی خارجی):
```bash
python main.py
```
(روی ویندوز اگر `python` شناخته نشد: `py main.py`)

## نمونه استفاده
```
===== Task Manager =====
1. Add task
2. Show tasks
3. Delete task
4. Mark task as done
5. Exit

Choose an option (1-5): 1
Task title: Finish homework
Task added.
```

## قالب داده (`tasks.json`)
```json
[
  { "id": 1, "title": "Finish homework", "done": false }
]
```

## نکات
- اگر فایل `tasks.json` وجود نداشته باشد یا خراب باشد، برنامه با لیست خالی شروع می‌کند.
- ورودی نامعتبر (عدد اشتباه، عنوان خالی، شناسه ناموجود) با پیام خطا مدیریت می‌شود.
